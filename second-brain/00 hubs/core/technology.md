# Technology

## Description

The **Technology** hub captures knowledge related to the creation, development, application, and impact of tools, systems, and methods designed to solve problems, extend human capabilities, and transform society.

This includes topics such as software development, hardware innovation, information technology, artificial intelligence, automation, engineering disciplines, communications systems, and emerging technologies.  
It also covers digital tools, platforms, programming languages, cybersecurity, user experience design, and the interplay between technology and daily life.

Use this hub to map notes about:

- Programming languages, software development practices, and frameworks
- Hardware systems — computers, mobile devices, networking
- Artificial intelligence, machine learning, and robotics
- Cloud infrastructure, SaaS platforms, and cybersecurity
- Human-computer interaction and user experience design
- Emerging technologies like quantum computing, biotech, and nanotech
- Ethical considerations and societal impacts of technology

This hub focuses on **the creation and application of tools and systems**, distinct from `[[core/science]]` (which handles empirical investigation) and `[[core/business]]` (which addresses economic value creation involving technology).
