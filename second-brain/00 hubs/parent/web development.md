# Web Development

## Description

The **Web Development** hub captures knowledge about the technologies, architectures, best practices, and workflows used to build and maintain websites, web applications, and online services.

This includes frontend development (HTML, CSS, JavaScript frameworks), backend development (server-side programming, databases, APIs), full-stack practices, responsive design, web performance optimization, accessibility standards (WCAG), SEO basics, and deployment of web solutions.  
It also touches on security, scalability, user experience, and trends in modern web architecture (e.g., JAMstack, serverless).

Use this hub to map notes about:

- Frontend technologies like HTML, CSS, JavaScript, React, Vue, etc.
- Backend technologies including Node.js, Django, Ruby on Rails, Flask
- API design and integration (REST, GraphQL)
- Responsive design principles and cross-device testing
- Accessibility standards for inclusive web development
- Web hosting, CDN usage, serverless deployment options
- Best practices for performance optimization and security hardening

This hub connects directly to `[[core/technology]]`, and naturally overlaps with `[[parent/user experience design]]`, `[[parent/software engineering]]`, and `[[parent/devops & infrastructure]]` when discussing deployment and scaling.
