# Software Engineering

## Description

The **Software Engineering** hub captures knowledge about the structured principles, methodologies, tools, and practices used to design, develop, test, deploy, and maintain high-quality software systems.

This includes topics such as software architecture, design patterns, version control, software testing, quality assurance, software development methodologies (e.g., Agile, Scrum, DevOps), technical debt management, scalability principles, and maintainability strategies.  
It also covers the human side of engineering — team collaboration, documentation standards, code review practices, and systems thinking.

Use this hub to map notes about:

- Software design principles (SOLID, DRY, YAGNI)
- Software development lifecycle models and methodologies
- Testing strategies: unit, integration, system, acceptance testing
- Version control systems, branching strategies, and release workflows
- Software architecture patterns (monolith, microservices, serverless)
- Best practices for code readability, refactoring, and documentation
- Engineering management practices (scaling teams, technical leadership)

This hub connects to `[[core/technology]]`, and often overlaps with `[[parent/programming languages]]`, `[[parent/devops & infrastructure]]`, and `[[parent/cybersecurity]]` where operational or security practices are involved.
