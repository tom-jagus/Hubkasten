# Programming Languages

## Description

The **Programming Languages** hub captures knowledge about the design, syntax, semantics, paradigms, and applications of languages used to instruct computers to perform tasks.

This includes major general-purpose languages (e.g., Python, JavaScript, C++), domain-specific languages, functional and object-oriented paradigms, and emerging languages focused on specific use cases like data science, embedded systems, or performance optimization.  
It also covers language comparisons, best practices, style guides, tooling ecosystems, and the philosophy and tradeoffs behind language design.

Use this hub to map notes about:

- Syntax, semantics, and idiomatic usage patterns
- Language ecosystems and tooling (compilers, interpreters, libraries, frameworks)
- Comparative strengths, weaknesses, and tradeoffs of different languages
- Programming paradigms (procedural, functional, object-oriented, declarative)
- Tips for choosing the right language for specific projects
- Historical evolution and trends in programming language development

This hub connects to `[[core/technology]]` and naturally overlaps with `[[parent/software engineering]]`, especially when discussing coding standards, system architecture, or collaborative development.
