# DevOps & Infrastructure

## Description

The **DevOps & Infrastructure** hub focuses on the practices, tools, and systems used to provision, deploy, monitor, and maintain reliable computing environments for software applications.

This includes cloud platforms (AWS, GCP, Azure), infrastructure-as-code (Terraform, Pulumi), CI/CD pipelines, containerization (Docker, Kubernetes), observability (logs, metrics, tracing), configuration management, and scalable system design.  
It also covers workflow automation, environment reproducibility, disaster recovery planning, and platform-level security and performance optimization.

Use this hub to map notes about:

- Setting up and managing development, staging, and production environments
- CI/CD design and orchestration tools (GitHub Actions, Jenkins, etc.)
- Infrastructure provisioning with Terraform, Ansible, or Helm
- Monitoring, alerting, and observability systems
- Managing cloud services, networking, and scaling policies
- DevOps culture, practices, and collaboration principles (DevSecOps, SRE)
- Container management and service orchestration (Docker, Kubernetes)

This hub links to `[[core/technology]]` and often intersects with `[[parent/software engineering]]`, `[[parent/automation & scripting]]`, and `[[parent/cybersecurity]]`.
