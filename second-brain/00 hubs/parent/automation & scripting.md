# Automation & Scripting

## Description

The **Automation & Scripting** hub focuses on the tools, techniques, and patterns used to automate repetitive or manual tasks, streamline workflows, and improve efficiency in both technical and non-technical domains.

This includes scripting languages (like Bash, Python, PowerShell), task schedulers, automation tools (e.g. cron, GitHub Actions, Zapier), macros, and integration between systems through APIs, CLIs, or no-code platforms.  
It also covers the design of scripts and automation routines that reduce human error, improve speed, and enable scalable systems administration, data processing, or development workflows.

Use this hub to map notes about:

- Writing scripts for task automation (shell, Python, etc.)
- Automating deployments, builds, or repetitive dev workflows
- Workflow orchestration tools and schedulers
- Connecting apps through APIs or no-/low-code tools
- Creating automations for file processing, backups, system setup
- CLI tooling, scripting best practices, and parameterized workflows

This hub belongs under `[[core/technology]]`, and may link to `[[parent/devops & infrastructure]]` or `[[parent/data systems]]` when automation targets cloud environments or data pipelines.
