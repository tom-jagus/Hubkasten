# Learning Methods & Systems

## Description

The **Learning Methods & Systems** hub captures frameworks, strategies, and meta-skills for acquiring and retaining knowledge effectively — across subjects, formats, and stages of life.

This includes study methods (e.g. Feynman Technique, SQ3R), cognitive strategies (e.g. spaced repetition, active recall), memory techniques, self-paced curriculum design, and workflows for organizing learning.  
It also supports experimentation with learning systems, evaluating learning effectiveness, and refining lifelong learning habits.

Use this hub to map notes about:

- Study techniques and memory systems
- Learning theories and cognitive science (e.g. Bloom’s Taxonomy, learning styles)
- Self-directed learning workflows or curriculum design
- Note condensation and review routines
- Tools or apps used for knowledge retention
- Personal experiments with learning efficiency
- Reflections on mindset, motivation, and discipline in learning

This hub connects to `[[core/education]]` and may overlap with `[[parent/study tools]]`, `[[core/workspace]]` (for systems and workflow), and `[[parent/knowledge sharing]]` when those systems are taught or shared.
