# Hardware Systems

## Description

The **Hardware Systems** hub captures knowledge related to the design, architecture, functioning, and optimization of physical computing devices and electronic systems.

This includes topics such as computer architecture, microprocessors, embedded systems, IoT devices, networking hardware, storage systems, and performance tuning.  
It also explores advances in chip design, low-level hardware programming, device manufacturing processes, and interactions between hardware and operating systems.

Use this hub to map notes about:

- CPU, GPU, and specialized hardware (e.g., TPUs, FPGAs)
- Embedded systems and microcontroller programming
- Internet of Things (IoT) architecture and security
- Networking devices: routers, switches, modems, edge computing nodes
- Storage technologies: SSDs, NVMe, SANs, NAS devices
- Hardware acceleration for AI, graphics, and data processing
- Power consumption, thermal management, and performance benchmarking

This hub connects to `[[core/technology]]`, and often overlaps with `[[parent/devops & infrastructure]]`, `[[parent/emerging tech]]`, and `[[parent/data systems]]` when discussing physical deployment platforms.
