# Data Systems

## Description

The **Data Systems** hub focuses on the technologies, architectures, and processes used to collect, store, manage, process, and retrieve structured and unstructured data.

This includes databases (SQL/NoSQL), data pipelines, ETL/ELT workflows, data modeling, warehousing, streaming systems, and modern data stack tools.  
It also covers topics like data governance, quality assurance, versioning, scalability, performance tuning, and integration with analytics or AI platforms.

Use this hub to map notes about:

- Relational and non-relational database technologies
- Data warehousing solutions (e.g., Snowflake, BigQuery, Redshift)
- Data pipeline orchestration (e.g., Airflow, dbt, Prefect)
- Query languages and optimization (SQL, GraphQL, etc.)
- Data architecture patterns and schema design
- Data lakehouse concepts, real-time streaming, and event-driven systems
- Best practices for managing data integrity, lineage, and observability

This hub connects directly to `[[core/technology]]` and often overlaps with `[[parent/software engineering]]`, `[[parent/artificial intelligence]]`, or `[[parent/devops & infrastructure]]` depending on deployment and use.
