# Contributing to Hubkasten

Thank you for considering contributing to Hubkasten!

## How to Contribute

- **Fix bugs**: correct errors in templates or scripts
- **Suggest improvements**: propose structural changes, better workflows
- **Create templates**: suggest new note types if relevant
- **Improve scripts**: enhance automation or add new features

## Process

1. Fork this repository
2. Create a branch (`git checkout -b feature-name`)
3. Commit your changes (`git commit -am 'Add new feature'`)
4. Push to the branch (`git push origin feature-name`)
5. Open a Pull Request

## Code Style

- Keep it clean and minimal.
- Comment scripts where logic is non-trivial.
- Prioritize readability over cleverness.

Happy note-taking and building!
