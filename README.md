# Hubkasten

A **modern, hub-driven evolution of Zettelkasten**, designed to scale your thinking, knowledge management, and learning using a second-brain structure.

Hubkasten organizes your notes with:

- **Hubs**: structured, curated topic nodes (instead of messy #tags)
- **Permanent Notes**: atomic, evergreen ideas
- **Source Notes**: structured knowledge capture with processing status

All content is stored in simple, portable **Markdown files** inside a clean folder structure, enabling full version control, automation, and future-proof scaling.

---

## 🚀 Quick Start

1. Clone or download this repository.
2. Open the `second-brain/` folder.
3. Duplicate the templates in `03 misc/templates/` to create your own notes, hubs, and sources.
4. Follow the README in `second-brain/` for full usage instructions.

Automation scripts (in `scripts/`) allow you to:

- Update Hub files automatically
- Track source processing
- Maintain your note network effortlessly
